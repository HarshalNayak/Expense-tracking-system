Personal Expense Tracker
A lightweight, console-based Python application designed to help users take control of their financial health. This tool allows for efficient logging, tracking, and categorization of daily expenses and income.

## Key Features
Transaction Logging: Easily add income and expenses with descriptions and amounts.

Categorization: Organize spending into categories (e.g., Food, Rent, Entertainment, Salary) for better insights.

Balance Overview: Real-time calculation of total balance based on recorded transactions.

Data Persistence: (Optional: Mention if you use a CSV/JSON file) Transactions are saved locally, ensuring your data is available every time you run the app.

Clean CLI Interface: Intuitive menu-driven navigation for a seamless user experience.
